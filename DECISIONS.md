# Decisions

- Original bounded stdlib profile instead of candidate adoption: preserves exact builtin/no-hook admission, explicit rollback and finite resource contracts without new dependencies. Retained upstream issues/source remain unexecuted comparison evidence.
- Six operations and private-copy discard fill the gap deferred by Pointer/Merge Patch; schema validation is a separate future concept. HTTP atomicity and resource authorization are not implemented.
- Root removal excluded so reports always have a JSON result. Integer-only and strict encoded spelling/Unicode admission are explicit subset choices, not full RFC compliance.
- Entire later/ignored input is validated before execution/support. Extra operation members are semantically ignored, keeping missing/null and meaningful/unused fields distinct.
- Clone each accepted working value and snapshot copied sources before insertion. Candidate growth is bounded but allocated before its result check; no intermediate value report. Source-existence precedes same-path move no-op; ancestry uses decoded tokens and destination uses post-removal state.
- Result report retains original value after rejection, completed-prefix trace and exit4. Exit1 distinguishes applied change; restoring the original value can still exit0. Diagnostics2/3 omit sensitive details.
- Sorted compact ASCII with LF and capped renderer enables exact-byte frozen comparisons. ECC found Windows stdout added CR; direct interpreter text-wrapper LF configuration fixes physical report spelling/cap consistency.
- No new repository/publication/installs, no edits to completed labs or parent/shared helpers. Current local receipts and vault milestone support coordinator review, not independent certification.
