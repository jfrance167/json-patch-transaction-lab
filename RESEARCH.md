## Recommendation and standards

Build an original stdlib six-operation bounded teaching profile; adopt neither dependency. JSON Patch addresses order, array shifts, preconditions and copying that prior Pointer lookup and Merge Patch replacement explicitly deferred. [RFC6902](https://www.rfc-editor.org/rfc/rfc6902.html) sections3–5 specify sequential application, add/remove/replace/move/copy/test, same-JSON-type test equality, existing sources, and terminating an unsuccessful patch. Move uses removal followed by addition and forbids a proper source-prefix destination. Unrecognized operation members are ignored. [RFC6901](https://www.rfc-editor.org/rfc/rfc6901.html) supplies exact plain-pointer escaping/index rules. [RFC5789](https://www.rfc-editor.org/rfc/rfc5789.html) section2 imposes atomic application on an HTTP server. Our discard-on-failure private-copy policy is a deliberate API design, not evidence every library rolls back or an HTTP implementation. Integer-only admission/root-delete exclusion are explicit subset limits.

Alternative [JSON Schema validation2020-12](https://json-schema.org/draft/2020-12/json-schema-validation): type/enum/object required/properties validation supplies a different learning gap. A narrow reference/regex-free subset is feasible, but does not explain index shifts or rollback. Deferred rather than combined into this lab.
