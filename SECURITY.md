# Security boundaries

This is a local supplied-synthetic-value teaching profile. No real system, file content/configuration, service, HTTP request, external reference, authentication or authorization decision is patched. Input values and report echoes must contain synthetic non-sensitive data only.

Exact-type native checks precede user hooks. Full recursive limits count aliases and reject cycles; bytes receive early numeric/depth gates, strict UTF-8, duplicate rejection and integer/Unicode admission. Every operation/ignored/later value is checked before support or execution. Private cloning, typed equality and contextual paths prevent accidental caller mutation and Python/JSON coercion. Per-step result checks stop continued growth; transient candidate allocation remains bounded rather than pre-rejected.

Reports/fixed diagnostics are capped before physical delivery, and stdout LF prevents Windows newline expansion. Exclusive output refuses existing files and aliases/hardlinks; observed file identity/size/time changes fail. This does not contain hostile filesystem races or guarantee atomic physical writes: partial output remains possible. Native concurrent mutation and arbitrary user-supplied render inputs are outside the API contract.

Verified only Windows CPython3.13.7 locally. No complete RFC conformance, independent audit, hosted checks or advisory/Scorecard/supply-chain certification. No own repository/history or hosted baseline exists under approved scope. Targeted source credential-signature checks have narrow coverage; no sensitive match text is printed. Review/validation records name actual scope and exclusions.
